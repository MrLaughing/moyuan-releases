# 墨园 Android 安装包

这里是墨园的公开发布仓库，只提供 Android 安装包、版本说明和应用内更新清单，不包含应用源代码。

墨园是一款把微信读书中的真实阅读时光转化为植物收藏与个人花园的轻养成应用。它包含四季与天气花园、50 种植物图鉴、阅读书案、微信读书同步和自定义花园布置。

## 下载与安装

1. 打开本仓库的 [Releases](https://github.com/MrLaughing/moyuan-releases/releases) 页面。
2. 选择最新稳定版本，下载名称为 `moyuan-v<版本>.apk` 的文件。
3. Android 首次安装站外 APK 时会要求允许当前下载工具“安装未知应用”，请只对可信来源临时授权。

系统要求：Android 8.0（API 26）或更高版本。

已安装墨园后，可在应用内进入“我的 > 检查更新”。应用会在内部完成以下流程：

- 从本仓库读取最新版本；
- 优先尝试国内 GitHub 代理，失败后自动回退 GitHub 官方线路；
- 在应用缓存目录下载 APK，不跳转浏览器或第三方下载器；
- 使用发布清单中的 SHA-256 校验安装包；
- 在获得系统“安装未知应用”权限后发起覆盖安装。

## 文件说明

- GitHub Releases：可安装 APK 和每个版本的更新说明。
- `latest.json`：应用内更新使用的机器可读清单，包含版本号、下载线路、文件大小和 SHA-256。

安装包由私有源码仓库的 GitHub Actions 使用固定 release keystore 构建和签名。公开仓库不会保存 keystore、密码、微信读书凭据或天气服务密钥。

## 完整性校验

每个版本的 SHA-256 会写入 `latest.json`。手动下载后可在 PowerShell 中验证：

```powershell
Get-FileHash .\moyuan-v2.1.0.apk -Algorithm SHA256
```

输出应与 `latest.json` 的 `sha256` 完全一致。校验不一致时不要安装，并从 Releases 官方页面重新下载。

正式安装包的签名证书 SHA-256 为：

```text
1e0daf5da40385fede3420c07c199efe2866e376e6852fb528d1b2c3bb6085a9
```

`v2.1.0` 是首个公开发行版，也是首个内置应用更新功能的版本；首次安装或从未公开分发的旧版本迁移时，需要先从 Releases 手动安装一次。
